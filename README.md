# Northstar Shop — eCommerce Homepage

eCommerce homepage for a fictional fashion store. Built as a portfolio project to demonstrate product grid layout, category cards, hover interactions, and add-to-cart animation.

## Live Demo

[northstar-shop on GitHub Pages](https://georgy-itech.github.io/ecommerce-homepage-showcase/)

## Features

- Category card grid with hover overlay
- Product grid with badge labels (New, Hot, Top Rated)
- Add to Cart button with pop animation (+1 counter)
- Fallback images on load error
- Responsive layout from 375px up
- Accessible markup with aria-labels on all interactive elements

## Tech Stack

- HTML5 (semantic, accessible)
- Pure CSS (custom properties, BEM, clamp())
- Vanilla JavaScript (no libraries)

## What I Practiced

- Product card layout with image hover zoom
- CSS grid for category and product grids
- Button micro-interaction (add to cart animation)
- Image error fallback in JS
- BEM naming across a complex multi-section page
